# phaser4-101
tutorials for learning the Phaser 4 TypeScript game library

NOTE:
- these tutorials are based on the open-source Phaser 4 TypeScript game library
  - use whatever IDE you choose
     - e.g. the free, open-source, cross-plaform [Celbridge workbench :-)](https://www.celbridge.org/)
- You can make Phaser 4 games without using their paid editor (I've never used it...)

## The phaser4-101 tutorials

1. single scene - move rectangle left and right with arrow keys
   - learn the steps to setup a new deno/Node Phaser 4 project from the official scaffolded template
   - (and update it to latest Phaser 4 version)
   - then replace default content with an all-in-one game script `main.ts` to start learning Phaser 4
   - https://github.com/dr-matt-smith/phaser4-101/blob/main/_learn_phaser_01/README_deno.md
